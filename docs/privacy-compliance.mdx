Rime is SOC 2 Type II certified and HIPAA compliant. By default, Rime collects only character counts and does not use customer data for model training. Email [support@rime.ai](mailto:support@rime.ai) to request compliance reports, an MSA, or a BAA.

## Data handling

Rime does not collect customer data beyond character count unless requested. Customer data is not used to train Rime models unless the customer explicitly opts in.

Set `trainableUtterance=true` on an API request to authorize training use for that utterance. When the parameter is omitted, it defaults to `false` and the data is not used for training.

Rime can sign an MSA or BAA to define customer-specific data and compliance terms.
