Set `speaker` on every TTS request. For a first Coda request, try `astra`; use the live catalog endpoints for the complete, current lineup.

```json
{
  "speaker": "astra",
  "text": "Hello from Rime!",
  "modelId": "coda",
  "lang": "en"
}
```

## Languages

Language support varies by model and deployment. As of August 2026, Rime's primary cloud models support the following languages:

| Language | ISO codes | Coda | Mist v3 |
| :--- | :--- | :---: | :---: |
| English | `eng` / `en` | ✅ | ✅ |
| Arabic | `ara` / `ar` | ✅ | ❌ |
| French | `fra` / `fr` | ✅ | ✅ |
| German | `ger` / `de` | ✅ | ✅ |
| Hindi | `hin` / `hi` | ✅ | ❌ |
| Japanese | `jpn` / `ja` | ✅ | ❌ |
| Portuguese | `por` / `pt` | ✅ | ❌ |
| Spanish | `spa` / `es` | ✅ | ✅ |

Mist v2 supports English, French, German, and Spanish. Cloud Arcana keeps its existing language coverage until requests switch to Coda on August 15, 2026. On-prem image coverage differs from the cloud matrix; see the [on-prem quickstart](/docs/on-prem/quickstart#tts-service).

<Note>**A voice serves one language, so picking a language narrows your choices.** Coda covers eight languages, but no individual Coda voice crosses between them: 121 of its 184 voices are English, then Spanish 25, Japanese 10, Portuguese 8, German 7, Arabic 6, French 5, and Hindi 2. Set `lang` to the language of the voice you chose. An unsupported pairing may not return an error, so verify against the [Coda catalog](/docs/voices-coda) rather than assuming a familiar voice speaks your language.</Note>

## Mist v3 voices

Mist v3 carries 78 voices with significantly lower TTFA than Mist v2. Most are drawn from the Mist v2 lineup, but the lineups are not identical: 71 speakers are shared, 67 Mist v2 speakers are not available on Mist v3, and 7 are Mist v3 only. Confirm a speaker before switching `modelId`.

See the [full voice list](/api-reference/data/voices) for available Mist v3 speakers.

## Mist v2 voices

Mist v2 is tuned for clarity, pronunciation accuracy, and high-throughput production. For new projects, prefer Mist v3.

See the [full voice list](/api-reference/data/voices) for available Mist v2 speakers.
