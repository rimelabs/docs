The public catalog publishes 78 Mist v3 voices. Pass the value in the Voice column as `speaker`, with `modelId` set to `mistv3` and `lang` set to the code given in the section you took the voice from.

5 of these voices serve more than one language and appear in more than one section below. The rest serve exactly one, so pairing a voice with a different `lang` is not a supported combination.

**To hear a voice, do not rely on the descriptions here.** Play it in the [Rime dashboard](https://app.rime.ai), or ask an assistant connected to the [hosted MCP server](/docs/mcp) to browse and synthesize a line for you: [`list_voices`](/mcp-reference/list-voices) needs no API key, and [`synthesize_speech`](/mcp-reference/synthesize-speech) uses yours. This page is a reference index for looking up what exists and what it works with.

Use your browser's find command to search by voice name, country, or description. For the machine-readable source, see [the voice details endpoint](/api-reference/data/voice-details).

Switching to Mist v3 from another model? A voice name is not carried by every model. If the voice you use today is not listed below, Mist v3 does not serve it and you need to choose a different one rather than change `modelId` alone.
