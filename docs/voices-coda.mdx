The public catalog publishes 184 Coda voices. Pass the value in the Voice column as `speaker`, with `modelId` set to `coda` and `lang` set to the code given in the section you took the voice from.

Each Coda voice serves exactly one language. Coda as a model covers 8 languages, but no individual voice crosses between them, so choosing a language narrows the voices available to you. Pairing a voice with a different `lang` is not a supported combination.
