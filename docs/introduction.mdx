Rime gives applications a natural, low-latency voice through one platform. Start with Coda for new work, then use HTTP or WebSockets from your backend. The dashboard, CLI, MCP server, and supported integrations provide other ways into the same system.

The [Rime dashboard](https://app.rime.ai/) provides a visual workspace for exploring voices and generating speech. The same speech capabilities are available to applications and developer tools through Rime's APIs.

## Start with Coda

Coda is the default model for new projects and the recommended destination for Arcana traffic. Existing Arcana integrations can switch by setting `modelId: coda`; the rest of the API contract stays the same.

Coda pairs an LLM backbone with a dedicated speech inference engine trained on full-duplex conversations between real people. It delivers top-rated voice quality in human evaluations, **sub-100ms model latency** (sub-200ms end to end over the cloud API), and one voice lineup across English, Spanish, French, Portuguese, German, and Japanese.
